### 🔐 What I'm building: LeahyAI

An AI-powered education platform for learners from Pre-K through PhD, built and secured end to end:

- **Nine production Python microservices** behind a hardened edge, with automated CI/CD and centralized secrets management
- **Identity first:** multi-factor authentication (TOTP and WebAuthn passkeys), role-based access, and per-service data isolation so one compromise stays contained
- **Tested adversarially:** structured attack testing of tenant isolation and session handling, with every finding fixed and verified in production
- **Compliance by design:** controls mapped to NIST SP 800-53 and 800-171, FERPA, PCI-DSS, and GLBA
- **Responsible AI:** human-in-the-loop review for AI decisions and a private path for protected student data
